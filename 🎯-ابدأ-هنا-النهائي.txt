📋 الخطوات المطلوبة (مرة واحدة فقط):

═══════════════════════════════════════════════════════════
   الخطوة 1: تحديث قاعدة البيانات
═══════════════════════════════════════════════════════════

1. افتح XAMPP Control Panel
2. اضغط Admin بجانب MySQL (يفتح phpMyAdmin)
3. اختر قاعدة البيانات "web scanner"
4. اضغط على تبويب SQL
5. انسخ والصق هذا الكود:

┌─────────────────────────────────────────────────────────┐
│ USE `web scanner`;                                      │
│                                                         │
│ -- إضافة جدول التصاريح                                 │
│ CREATE TABLE IF NOT EXISTS authorizations (            │
│   id VARCHAR(36) PRIMARY KEY,                          │
│   organization_name VARCHAR(255) NOT NULL,             │
│   contact_person VARCHAR(255) NOT NULL,                │
│   contact_email VARCHAR(255) NOT NULL,                 │
│   contact_phone VARCHAR(50),                           │
│   target_scope TEXT NOT NULL,                          │
│   allowed_operations TEXT NOT NULL,                    │
│   valid_from DATETIME NOT NULL,                        │
│   valid_until DATETIME NOT NULL,                       │
│   status ENUM('ACTIVE','EXPIRED','REVOKED')            │
│     DEFAULT 'ACTIVE',                                  │
│   created_by INT,                                      │
│   created_at DATETIME DEFAULT CURRENT_TIMESTAMP,       │
│   updated_at DATETIME DEFAULT CURRENT_TIMESTAMP        │
│     ON UPDATE CURRENT_TIMESTAMP                        │
│ );                                                      │
│                                                         │
│ -- إضافة تصريح تجريبي                                 │
│ INSERT INTO authorizations (                           │
│   id, organization_name, contact_person,               │
│   contact_email, target_scope,                         │
│   allowed_operations, valid_from, valid_until,         │
│   status, created_by                                   │
│ ) VALUES (                                              │
│   UUID(), 'شركة الاختبار', 'مدير الأمن',              │
│   'security@test.com',                                 │
│   'https://example.com',                               │
│   'WEB_SCAN,NETWORK_TEST,PHISHING_CAMPAIGN',           │
│   NOW(), DATE_ADD(NOW(), INTERVAL 1 YEAR),             │
│   'ACTIVE', 1                                          │
│ );                                                      │
└─────────────────────────────────────────────────────────┘

6. اضغط Go أو تنفيذ

═══════════════════════════════════════════════════════════
   الخطوة 2: تشغيل النظام
═══════════════════════════════════════════════════════════

شغل الملف:

   تشغيل-النظام-النهائي.bat

أو يدوياً:

   set PORT=3001
   node server-full-mysql.js

═══════════════════════════════════════════════════════════
   الخطوة 3: فتح النظام
═══════════════════════════════════════════════════════════

افتح المتصفح:

   http://localhost:3001

🔐 بيانات الدخول:

   اسم المستخدم: admin
   كلمة المرور: 123456
