📋 الخطوات التالية (3 خطوات فقط):

┌─────────────────────────────────────────────────────────┐
│  الخطوة 1: أعد تشغيل الخادم                            │
└─────────────────────────────────────────────────────────┘

   طريقة 1 (سريعة):
   taskkill /F /IM node.exe
   npm start

   طريقة 2 (أسهل):
   شغل: 🔥-حل-سريع.bat


┌─────────────────────────────────────────────────────────┐
│  الخطوة 2: امسح Cache المتصفح                          │
└─────────────────────────────────────────────────────────┘

   1. Ctrl + Shift + Delete
   2. اختر "Cached images and files"
   3. اضغط "Clear data"
   4. Ctrl + F5 (إعادة تحميل)


┌─────────────────────────────────────────────────────────┐
│  الخطوة 3: جرب مرة أخرى                                │
└─────────────────────────────────────────────────────────┘

   1. افتح: http://localhost:3000
   2. اذهب إلى "تحليل الشبكات"
   3. "بدء عملية جديدة" > "تحليل الشبكة"
   4. املأ النموذج:
      - اختر تصريح
      - BSSID: 4a:1f:4c:46:18:2b
      - SSID: faraa net
      - اختر نوع اختبار
   5. اضغط "بدء التحليل"
