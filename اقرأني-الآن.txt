الطريقة 1: Docker (الأسهل) 🐳
────────────────────────────────────────────────────────
1. افتح الملف: ابدأ-هنا.html
2. اتبع تعليمات "الخيار 1: Docker"
3. أو شغّل: تحميل-docker.ps1

لماذا Docker؟
• يثبت كل شيء تلقائياً
• يشغل بأمر واحد فقط
• لا حاجة لإعدادات معقدة


الطريقة 2: التثبيت اليدوي 🔧
────────────────────────────────────────────────────────
1. حمّل PostgreSQL من:
   https://www.postgresql.org/download/windows/

2. حمّل Redis من:
   https://github.com/microsoftarchive/redis/releases

3. ثبّتهما وشغّلهما

4. عدّل ملف .env بكلمة مرور PostgreSQL

5. شغّل: npm run dev
