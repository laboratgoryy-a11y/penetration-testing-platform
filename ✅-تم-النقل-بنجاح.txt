📋 الخطوات التالية:
═══════════════════════════════════════════════════════════

1. تثبيت mysql2:
   npm install mysql2

2. إنشاء ملف .env:
   DB_HOST=localhost
   DB_PORT=3306
   DB_NAME=penetration_testing_platform
   DB_USER=root
   DB_PASSWORD=
   
   PORT=3001
   NODE_ENV=development
   JWT_SECRET=your-secret-key

3. إنشاء قاعدة البيانات في phpMyAdmin:
   - افتح: http://localhost/phpmyadmin
   - أنشئ قاعدة بيانات: penetration_testing_platform
   - Collation: utf8mb4_unicode_ci

4. استيراد Schema:
   - اختر القاعدة من القائمة اليسرى
   - تبويب Import
   - اختر: src/database/schema.sql
   - اضغط Go

5. اختبار الاتصال:
   node test-mysql-connection.js

6. تشغيل النظام:
   npm start
