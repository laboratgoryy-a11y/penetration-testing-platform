📋 الخطوات النهائية للتشغيل:
═══════════════════════════════════════════════════════════

الخطوة 1: تثبيت mysql2
───────────────────────────────────────────────────────────
npm install mysql2

الخطوة 2: إنشاء قاعدة البيانات
───────────────────────────────────────────────────────────
□ افتح phpMyAdmin: http://localhost/phpmyadmin
□ أنشئ قاعدة بيانات: penetration_testing_platform
□ Collation: utf8mb4_unicode_ci

الخطوة 3: استيراد Schema
───────────────────────────────────────────────────────────
□ اختر القاعدة من القائمة اليسرى
□ تبويب Import
□ اختر: src/database/schema.sql
□ اضغط Go

الخطوة 4: إنشاء ملف .env
───────────────────────────────────────────────────────────
أنشئ ملف .env في جذر المشروع:

DB_HOST=localhost
DB_PORT=3306
DB_NAME=penetration_testing_platform
DB_USER=root
DB_PASSWORD=

PORT=3001
NODE_ENV=development
API_VERSION=v1

JWT_SECRET=your-super-secret-jwt-key-change-this
JWT_EXPIRES_IN=24h

الخطوة 5: بناء المشروع
───────────────────────────────────────────────────────────
npm run build

الخطوة 6: تشغيل النظام
───────────────────────────────────────────────────────────
npm start

🔧 إذا واجهت مشاكل:

  الحل: npm install mysql2

  الحل: أنشئ قاعدة البيانات أولاً

المشكلة: "ECONNREFUSED"
  الحل: شغل MySQL في XAMPP

المشكلة: أخطاء TypeScript
  الحل: npm run build --force
