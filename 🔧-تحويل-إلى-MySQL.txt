2️⃣ شغّل ملف التثبيت:
   setup-mysql.bat

═══════════════════════════════════════════════════════════════

📋 التثبيت اليدوي:
═══════════════════════════════════════════════════════════════

1. تثبيت مكتبة MySQL:
   npm install mysql2

2. إنشاء قاعدة البيانات:
   - افتح phpMyAdmin: http://localhost/phpmyadmin
   - انسخ محتوى: src/database/schema-mysql.sql
   - الصق في SQL واضغط Go

3. إنشاء ملف .env:
   DB_HOST=localhost
   DB_PORT=3306
   DB_NAME=penetration_testing_platform
   DB_USER=root
   DB_PASSWORD=

4. استبدال ملف الاتصال:
   copy src\database\connection-mysql.ts src\database\connection.ts

5. تشغيل السيرفر:
   node server-complete.js

🔄 الفروقات التي تم التعامل معها:
═══════════════════════════════════════════════════════════════

PostgreSQL → MySQL:
  $1, $2, $3 → ?, ?, ? (تحويل تلقائي)
  SERIAL → AUTO_INCREMENT
  BOOLEAN → TINYINT(1)
  TEXT[] → JSON
  TIMESTAMP WITH TIME ZONE → TIMESTAMP

Redis → In-Memory:
  getRedisClient() → getSession(key)
  client.set() → setSession(key, value, ttl)
  client.get() → getSession(key)
  client.del() → deleteSession(key)
