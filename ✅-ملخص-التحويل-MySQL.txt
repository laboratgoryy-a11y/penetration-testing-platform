🚀 خطوات التشغيل السريعة:
═══════════════════════════════════════════════════════════

الخطوة 1: شغل MySQL في XAMPP
   □ افتح XAMPP Control Panel
   □ اضغط Start بجانب MySQL

الخطوة 2: أنشئ قاعدة البيانات
   □ افتح: http://localhost/phpmyadmin
   □ أنشئ قاعدة بيانات: penetration_testing_platform
   □ Collation: utf8mb4_unicode_ci

الخطوة 3: استورد Schema
   □ اختر القاعدة من القائمة اليسرى
   □ تبويب Import
   □ اختر: src/database/schema-mysql-complete.sql
   □ اضغط Go

الخطوة 4: حول النظام
   □ اضغط مرتين على: 🔄-تحويل-إلى-MySQL.bat
   □ أو يدوياً:
     - انسخ connection-mysql-complete.ts إلى connection.ts
     - npm install mysql2
     - أنشئ ملف .env

الخطوة 5: شغل النظام
   □ npm start
   □ افتح: http://localhost:3001/login.html
