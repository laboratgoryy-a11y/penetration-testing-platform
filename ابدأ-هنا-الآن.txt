═══════════════════════════════════════════════════════════

📌 الخطوة 1: تشغيل النظام
───────────────────────────────────────────────────────────
انقر نقراً مزدوجاً على:
    تشغيل-النظام.bat

ثم اختر:
    [1] تشغيل النظام الكامل


📌 الخطوة 2: تسجيل الدخول
───────────────────────────────────────────────────────────
سيفتح المتصفح تلقائياً على:
    http://localhost:3001/login.html

بيانات الدخول:
    اسم المستخدم: admin
    كلمة المرور: password


📌 الخطوة 3: إنشاء تصريح (إذا لم يكن موجوداً)
───────────────────────────────────────────────────────────
1. اذهب إلى قسم "التصاريح"
2. انقر "تصريح جديد"
3. املأ البيانات:
   - اسم المنظمة: شركة اختبار
   - النطاق: example.com
   - العمليات المسموحة: اختر "الكل"
   - تاريخ الانتهاء: اختر تاريخ مستقبلي


📌 الخطوة 4: بدء فحص ويب
───────────────────────────────────────────────────────────
1. اذهب إلى "لوحة التحكم"
2. انقر "عملية جديدة"
3. اختر "فحص الويب"
4. املأ البيانات:
   - التصريح: اختر التصريح الذي أنشأته
   - URL: http://testphp.vulnweb.com
   - نطاق الفحص: فحص كامل
5. انقر "بدء الفحص"


📌 الخطوة 5: مراقبة التقدم
───────────────────────────────────────────────────────────
ستظهر نافذة منبثقة تعرض:
    ✓ شريط التقدم
    ✓ عدد الصفحات المفحوصة
    ✓ عدد الثغرات المكتشفة
    ✓ سجل الفحص


📌 الخطوة 6: عرض النتائج
───────────────────────────────────────────────────────────
بعد اكتمال الفحص:
    ✓ ستظهر النتائج في النافذة المنبثقة
    ✓ يمكنك النقر على "عرض التفاصيل الكاملة"


═══════════════════════════════════════════════════════════
    🔧 أدوات التتبع (للمطورين)
═══════════════════════════════════════════════════════════

إذا واجهت مشكلة في عرض الثغرات:

1. شغل النظام:
   تشغيل-النظام.bat → [1]

2. افتح أدوات التتبع:
   تشغيل-النظام.bat → [8]

3. ستفتح 3 صفحات:
   ✓ debug-scan-flow.html (تتبع المسار الكامل)
   ✓ test-vuln-api.html (اختبار API)
   ✓ test-scan-results.html (عرض النتائج)

4. افتح Console في المتصفح:
   اضغط F12 → Console

5. راقب السجلات التفصيلية


═══════════════════════════════════════════════════════════
    ⚡ أوامر سريعة
═══════════════════════════════════════════════════════════

تشغيل النظام:
    إدارة-سريعة.bat start

إيقاف النظام:
    إدارة-سريعة.bat stop

إعادة تشغيل:
    إدارة-سريعة.bat restart

عرض الحالة:
    إدارة-سريعة.bat status

فتح الواجهة:
    إدارة-سريعة.bat open

أدوات التتبع:
    إدارة-سريعة.bat debug
