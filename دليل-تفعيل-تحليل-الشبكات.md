# 🌐 دليل تفعيل نظام تحليل الشبكات (Network Analyzer)

## 📋 نظرة عامة

نظام تحليل الشبكات موجود بالكامل في المشروع ويتضمن:
- ✅ Backend API كامل (`src/api/routes/network.routes.ts`)
- ✅ خدمات الفحص الحقيقي (`RealNetworkScanner.ts`)
- ✅ واجهة أمامية (`network-analyzer-manager.js`)
- ✅ نظام التصاريح والأمان

**المشكلة الحالية:** النظام غير مفعّل ويعرض "0" نتائج لأن:
1. الفحص الحقيقي معطّل في الإعدادات
2. لا توجد واجهة لبدء فحص جديد
3. قاعدة البيانات فارغة (لا توجد فحوصات سابقة)

## 🚀 خطوات التفعيل

### الخطوة 1️⃣: تفعيل الفحص الحقيقي

#### أ) تحديث ملف `.env`

افتح ملف `.env` وغيّر هذا السطر:

```bash
# قبل التعديل
ENABLE_REAL_NETWORK_SCANNING=false

# بعد التعديل
ENABLE_REAL_NETWORK_SCANNING=true

# اختياري: تحديد واجهة الشبكة اللاسلكية
NETWORK_INTERFACE=wlan0  # أو wlan1 أو wlp3s0 حسب نظامك
NETWORK_SCAN_TIMEOUT=60
```

#### ب) التحقق من واجهة الشبكة اللاسلكية

على Linux/Mac:
```bash
# عرض جميع واجهات الشبكة
ip link show
# أو
iwconfig

# ستجد شيء مثل:
# wlan0, wlan1, wlp3s0, etc.
```

على Windows:
```powershell
# عرض واجهات الشبكة
netsh wlan show interfaces
```

---

### الخطوة 2️⃣: تثبيت الأدوات المطلوبة (Linux فقط)

النظام يستخدم أدوات Linux للفحص الحقيقي:

```bash
# على Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y wireless-tools iw nmap tcpdump aircrack-ng

# على Fedora/RHEL
sudo dnf install -y wireless-tools iw nmap tcpdump aircrack-ng

# على Arch Linux
sudo pacman -S wireless_tools iw nmap tcpdump aircrack-ng
```

**ملاحظة:** على Windows، النظام سيعمل في وضع المحاكاة (Simulation Mode) تلقائياً.

---

### الخطوة 3️⃣: إنشاء تصريح (Authorization)

قبل بدء أي فحص، يجب إنشاء تصريح قانوني:

#### أ) من خلال الواجهة:

1. افتح المتصفح: `http://localhost:3000`
2. سجّل الدخول كـ Admin
3. اذهب إلى قسم "التصاريح" (Authorizations)
4. اضغط "إنشاء تصريح جديد"
5. املأ البيانات:
   ```
   النوع: NETWORK_ANALYSIS
   النطاق: NETWORK
   القيمة: اسم الشبكة (SSID) أو * للجميع
   تاريخ البدء: اليوم
   تاريخ الانتهاء: بعد شهر
   ```

#### ب) من خلال API مباشرة:

```bash
curl -X POST http://localhost:3000/api/v1/authorizations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "type": "NETWORK_ANALYSIS",
    "scope": {
      "type": "NETWORK",
      "value": "*"
    },
    "startDate": "2024-01-01",
    "endDate": "2024-12-31",
    "approvedBy": "admin",
    "notes": "تصريح لفحص جميع الشبكات"
  }'
```

## 🧪 اختبار النظام

### 1. افتح صفحة الاختبار:
```
http://localhost:3000/test-network-analyzer.html
```

### 2. احصل على معرّف التصريح:
- اذهب إلى قسم التصاريح في النظام
- انسخ معرّف التصريح (UUID)

### 3. اكتشف الشبكات:
- الصق معرّف التصريح
- اضغط "اكتشاف الشبكات"
- ستظهر قائمة بالشبكات المتاحة

### 4. ابدأ فحص:
- أدخل SSID و BSSID من القائمة
- اختر نوع الفحص
- اضغط "بدء الفحص"

### 5. راقب التقدم:
- اضغط "تحديث الحالة" لمعرفة حالة الفحص
- عند الانتهاء، اضغط "عرض النتائج"

## 📊 فهم النتائج

### أنواع الثغرات المكتشفة:

1. **WEP_ENCRYPTION** (حرج)
   - الشبكة تستخدم تشفير WEP القديم
   - يمكن كسره في دقائق

2. **WEAK_PASSWORD** (حرج)
   - كلمة المرور ضعيفة
   - تم كسرها باستخدام قاموس

3. **WPS_ENABLED** (عالي)
   - WPS مفعّل ويمكن استغلاله

4. **EVIL_TWIN_VULNERABLE** (عالي)
   - الشبكة عرضة لهجوم Evil Twin

5. **INSECURE_PROTOCOLS** (متوسط)
   - بروتوكولات غير آمنة (HTTP, FTP, TELNET)

6. **UNENCRYPTED_DNS** (منخفض)
   - DNS غير مشفر

## 🔧 استكشاف الأخطاء

### المشكلة: "No valid authorization found"
**الحل:**
- تأكد من إنشاء تصريح صحيح
- تحقق من تاريخ البدء والانتهاء
- تأكد من أن النطاق يشمل الشبكة المستهدفة

### المشكلة: "Network scanning tools not found"
**الحل:**
```bash
# تثبيت الأدوات المطلوبة
sudo apt-get install wireless-tools iw nmap tcpdump
```

### المشكلة: "Permission denied"
**الحل:**
```bash
# تشغيل السيرفر بصلاحيات root (للفحص الحقيقي فقط)
sudo npm start
```

### المشكلة: النتائج تظهر "0"
**الأسباب المحتملة:**
1. لم يتم بدء أي فحص بعد
2. الفحص لا يزال قيد التنفيذ
3. الفحص فشل (تحقق من الـ logs)
