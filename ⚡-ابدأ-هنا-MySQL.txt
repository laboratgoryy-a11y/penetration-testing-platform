🎯 الهدف: تحويل النظام من PostgreSQL إلى MySQL (XAMPP)

═══════════════════════════════════════════════════════════
📋 المتطلبات (تأكد من توفرها):
═══════════════════════════════════════════════════════════

□ XAMPP مثبت
□ MySQL يعمل في XAMPP
□ Node.js مثبت
□ npm متاح
□ المشروع موجود

═══════════════════════════════════════════════════════════
🚀 الخطوات (5 خطوات فقط):
═══════════════════════════════════════════════════════════

الخطوة 1: شغل MySQL
═══════════════════════════════════════════════════════════
□ افتح XAMPP Control Panel
□ اضغط "Start" بجانب MySQL
□ انتظر حتى يصبح أخضر
□ تأكد من عمل phpMyAdmin: http://localhost/phpmyadmin

الخطوة 2: أنشئ قاعدة البيانات
═══════════════════════════════════════════════════════════
□ افتح phpMyAdmin
□ اضغط "New" في القائمة اليسرى
□ اسم القاعدة: penetration_testing_platform
□ Collation: utf8mb4_unicode_ci
□ اضغط "Create"

الخطوة 3: استورد الجداول
═══════════════════════════════════════════════════════════
□ اختر قاعدة البيانات من القائمة اليسرى
□ اضغط تبويب "Import"
□ اضغط "Choose File"
□ اختر: src/database/schema-mysql-complete.sql
□ اضغط "Go"
□ انتظر رسالة النجاح

الخطوة 4: حول النظام
═══════════════════════════════════════════════════════════
□ اضغط مرتين على: 🔄-تحويل-إلى-MySQL.bat
□ انتظر حتى يكتمل
□ تأكد من رسالة "✅ اكتمل التحويل!"

الخطوة 5: شغل النظام
═══════════════════════════════════════════════════════════
□ افتح PowerShell أو CMD
□ اذهب إلى مجلد المشروع
□ شغل: npm start
□ انتظر رسالة "✓ Server running on port 3001"

═══════════════════════════════════════════════════════════
✅ التحقق من النجاح:
═══════════════════════════════════════════════════════════

يجب أن ترى في Console:
  ✓ MySQL connected successfully
  ✓ Database connection established
  ✓ Server running on port 3001

اختبر:
  □ افتح: http://localhost:3001/health
  □ يجب أن ترى: {"success": true}
  
  □ افتح: http://localhost:3001/login.html
  □ سجل الدخول بأي بيانات
  □ يجب أن تنجح العملية

═══════════════════════════════════════════════════════════
🔧 إذا واجهت مشاكل:
═══════════════════════════════════════════════════════════

المشكلة: "ER_ACCESS_DENIED_ERROR"
  الحل: عدل ملف .env وأضف كلمة المرور

المشكلة: "ER_BAD_DB_ERROR"
  الحل: تأكد من إنشاء قاعدة البيانات (الخطوة 2)

المشكلة: "ECONNREFUSED"
  الحل: تأكد من تشغيل MySQL في XAMPP

المشكلة: "Cannot find module 'mysql2'"
  الحل: شغل: npm install mysql2
