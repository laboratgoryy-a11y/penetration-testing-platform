المشكلة:
─────────
هناك عملية تثبيت أو أمر معلق يطلب تأكيداً [Y] Yes أو [N] No

الحل (اختر واحداً):
═══════════════════════════════════════════════════════════════════

✓ الحل 1: إنهاء العمليات المعلقة
───────────────────────────────────────
1. افتح Task Manager (مدير المهام)
   اضغط: Ctrl + Shift + Esc

2. ابحث عن هذه العمليات وأنهها:
   - winget.exe
   - msiexec.exe
   - powershell.exe (إذا كان معلقاً)

3. أغلق جميع نوافذ PowerShell و CMD

4. افتح PowerShell جديد كمسؤول (Run as Administrator)

5. انتقل لمجلد المشروع:
   cd "المسار\الكامل\للمشروع"

6. جرب الأمر:
   node --version

═══════════════════════════════════════════════════════════════════

✓ الحل 2: إعادة تشغيل الجهاز
───────────────────────────────
1. أعد تشغيل الجهاز (Restart)
2. افتح PowerShell جديد
3. انتقل لمجلد المشروع
4. جرب الأمر: node --version

═══════════════════════════════════════════════════════════════════

✓ الحل 3: تثبيت Node.js يدوياً
────────────────────────────────
1. انقر نقراً مزدوجاً على ملف: nodejs-installer.msi
2. اتبع خطوات التثبيت
3. أعد تشغيل PowerShell
4. جرب الأمر: node --version

═══════════════════════════════════════════════════════════════════
