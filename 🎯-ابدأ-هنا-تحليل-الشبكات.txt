🌐 نظام تحليل الشبكات - دليل البدء السريع
═══════════════════════════════════════════════════════════════

✅ النظام موجود بالكامل ويعمل!

المشكلة الحالية: يظهر "0" نتائج لأن:
  1. الفحص الحقيقي معطّل (افتراضياً)
  2. لا توجد فحوصات سابقة في قاعدة البيانات
  3. لم يتم بدء أي فحص جديد

═══════════════════════════════════════════════════════════════
📋 خطوات التفعيل (5 دقائق)
═══════════════════════════════════════════════════════════════

الخطوة 1️⃣: تفعيل الفحص (اختياري)
────────────────────────────────────
افتح ملف .env وغيّر:
  ENABLE_REAL_NETWORK_SCANNING=true

ملاحظة: على Windows سيعمل في وضع المحاكاة تلقائياً


الخطوة 2️⃣: إعادة تشغيل السيرفر
────────────────────────────────────
  npm start


الخطوة 3️⃣: إنشاء تصريح
────────────────────────────────────
شغّل:
  node create-network-authorization.js

أو على Windows:
  تشغيل-تحليل-الشبكات.bat

انسخ معرّف التصريح (UUID) الذي سيظهر


الخطوة 4️⃣: افتح واجهة الاختبار
────────────────────────────────────
  http://localhost:3000/test-network-analyzer.html


الخطوة 5️⃣: ابدأ الفحص
────────────────────────────────────
  1. الصق معرّف التصريح
  2. اضغط "اكتشاف الشبكات"
  3. اختر شبكة
  4. اضغط "بدء الفحص"
  5. انتظر النتائج (2-10 دقائق)

🔧 حل المشاكل الشائعة
═══════════════════════════════════════════════════════════════

❌ "No valid authorization found"
   → أنشئ تصريح جديد: node create-network-authorization.js

❌ النتائج تظهر "0"
   → ابدأ فحص جديد من صفحة الاختبار
   → انتظر حتى ينتهي الفحص (تحقق من الحالة)

❌ "Permission denied" (Linux فقط)
   → شغّل بصلاحيات root: sudo npm start

❌ "Network scanning tools not found"
   → ثبّت الأدوات: sudo apt-get install iw nmap tcpdump
   → أو استخدم وضع المحاكاة: ENABLE_REAL_NETWORK_SCANNING=false
