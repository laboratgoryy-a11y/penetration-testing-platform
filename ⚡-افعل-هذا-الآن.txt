المشكلة: قاعدة البيانات لا تحتوي على عمود password

═══════════════════════════════════════════════════════════
   الخطوة 1: تحديث قاعدة البيانات
═══════════════════════════════════════════════════════════

1. افتح XAMPP Control Panel
2. اضغط Admin بجانب MySQL
3. اختر قاعدة البيانات "web scanner"
4. اضغط على تبويب SQL
5. انسخ والصق هذا الكود:

┌─────────────────────────────────────────────────────────┐
│ ALTER TABLE users ADD COLUMN password VARCHAR(255);    │
│ ALTER TABLE users ADD COLUMN email VARCHAR(255);       │
│                                                         │
│ UPDATE users SET password = '123456',                  │
│   email = 'admin@example.com' WHERE name = 'admin';   │
│                                                         │
│ UPDATE users SET password = '123456',                  │
│   email = 'user1@example.com' WHERE name = 'user1';   │
│                                                         │
│ UPDATE users SET password = '123456',                  │
│   email = 'user2@example.com' WHERE name = 'user2';   │
└─────────────────────────────────────────────────────────┘

6. اضغط Go أو تنفيذ

═══════════════════════════════════════════════════════════
   الخطوة 2: افتح النظام
═══════════════════════════════════════════════════════════

افتح المتصفح:

   http://localhost:3002/

استخدم:
   اسم المستخدم: admin
   كلمة المرور: 123456
