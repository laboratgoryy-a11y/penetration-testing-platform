🔒 دليل تشغيل منصة اختبار الاختراق

⚠️ المشكلة الحالية

هناك عملية معلقة في النظام تطلب تأكيداً [Y] Yes أو [N] No

🔧 حل المشكلة المعلقة

الحل 1: إنهاء العمليات المعلقة

  1. افتح Task Manager (مدير المهام) بالضغط على: Ctrl + Shift + Esc
  2. ابحث عن هذه العمليات وأنهها (End Task):
    • winget.exe
    • msiexec.exe
    • powershell.exe (إذا كان معلقاً)
  3. أغلق جميع نوافذ PowerShell و CMD
  4. افتح PowerShell جديد كمسؤول (Run as Administrator)

الحل 2: إعادة تشغيل الجهاز

أسهل حل: أعد تشغيل الجهاز (Restart) ثم افتح PowerShell جديد

🚀 طرق تشغيل النظام

✅ الطريقة الموصى بها: Docker

Docker سيقوم بتثبيت وتشغيل كل شيء تلقائياً (Node.js + PostgreSQL + Redis)

  1. حمل Docker Desktop من: هنا
  2. ثبته وأعد تشغيل الجهاز
  3. شغل Docker Desktop
  4. انقر نقراً مزدوجاً على ملف: START-DOCKER.bat

📦 الطريقة البديلة: Node.js مباشرة

  1. انقر نقراً مزدوجاً على ملف: nodejs-installer.msi
  2. اتبع خطوات التثبيت
  3. أعد تشغيل PowerShell
  4. ثبت PostgreSQL من: هنا
  5. ثبت Redis من: هنا
  6. انقر نقراً مزدوجاً على ملف: START.bat

📋 الأوامر اليدوية (إذا لزم الأمر)

بعد حل المشكلة المعلقة، يمكنك تشغيل هذه الأوامر في PowerShell:

# التحقق من Node.js
node --version
npm --version

# إعداد ملف البيئة
copy .env.example .env

# تثبيت المكتبات
npm install

# تشغيل النظام
npm run dev

🌐 الوصول للنظام

بعد التشغيل الناجح، افتح المتصفح على:

  • النظام الرئيسي: http://localhost:3000
  • توثيق API: http://localhost:3000/api-docs

📁 الملفات المساعدة

الملف الوصف
START-DOCKER.bat تشغيل النظام باستخدام Docker
START.bat تشغيل النظام باستخدام Node.js
KILL-PENDING.bat إنهاء العمليات المعلقة
check-system.ps1 فحص متطلبات النظام
دليل-التشغيل-السريع.md دليل نصي مفصل

❓ حل المشاكل الشائعة

المشكلة: "node is not recognized"

الحل: أعد تشغيل PowerShell بعد تثبيت Node.js، أو أعد تشغيل الجهاز

المشكلة: "Cannot connect to database"

الحل: تأكد من تشغيل PostgreSQL و Redis، أو استخدم Docker

المشكلة: "Port 3000 already in use"

الحل: غير المنفذ في ملف .env إلى PORT=3001

🎯 الخطوات المختصرة

2️⃣ ثبت Docker Desktop
3️⃣ شغل ملف START-DOCKER.bat
4️⃣ افتح http://localhost:3000
