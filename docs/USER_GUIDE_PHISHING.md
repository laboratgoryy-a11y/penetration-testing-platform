# دليل حملات التصيد الاحتيالي التدريبية

## نظرة عامة

محرك هجمات التصيد الاحتيالي هو أداة متقدمة لإنشاء وإدارة حملات تصيد احتيالي تدريبية. الهدف هو اختبار وعي الموظفين بالأمن السيبراني وتحديد نقاط الضعف البشرية.

## ⚠️ تحذير قانوني وأخلاقي

**تحذير حاسم:** يجب الحصول على موافقة كتابية صريحة من إدارة المنظمة قبل إطلاق أي حملة تصيد احتيالي. إرسال رسائل تصيد بدون موافقة يعتبر:
- جريمة جنائية (احتيال إلكتروني)
- انتهاكاً لقوانين مكافحة البريد المزعج
- سبباً للمساءلة القانونية والمدنية

**المبادئ الأخلاقية:**
- الهدف هو التدريب والتوعية، ليس الإحراج
- يجب إبلاغ الأهداف بعد انتهاء الحملة
- لا تستخدم البيانات المجمعة لأغراض ضارة
- احترم خصوصية الموظفين

## مفاهيم أساسية

### ما هي حملة التصيد التدريبية؟

حملة تصيد تدريبية هي محاكاة لهجوم تصيد احتيالي حقيقي بهدف:
1. اختبار وعي الموظفين بالأمن السيبراني
2. تحديد الموظفين الذين يحتاجون لتدريب إضافي
3. قياس فعالية برامج التوعية الأمنية
4. تحسين الثقافة الأمنية في المنظمة

### أنواع حملات التصيد

#### 1. حصاد بيانات الاعتماد (Credential Harvesting)
محاكاة صفحة تسجيل دخول لجمع أسماء المستخدمين وكلمات المرور.

**مثال:** صفحة تسجيل دخول مزيفة لـ Office 365

#### 2. تنزيل الملفات الضارة (Malware Download)
محاكاة تنزيل ملف ضار لاختبار وعي الموظفين بالملفات المشبوهة.

**مثال:** رسالة تطلب تنزيل "فاتورة" أو "تقرير مهم"

#### 3. استطلاعات وهمية (Fake Surveys)
استطلاعات تطلب معلومات حساسة.

**مثال:** "استطلاع رضا الموظفين" يطلب معلومات شخصية

#### 4. تحديثات عاجلة (Urgent Updates)
رسائل تدعي الحاجة لتحديث عاجل.

**مثال:** "تحديث أمني عاجل لحسابك"

### مكونات الحملة

#### 1. قالب البريد الإلكتروني
- الموضوع
- المحتوى
- المرسل
- روابط التتبع

#### 2. صفحة الهبوط (Landing Page)
- تصميم الصفحة
- حقول الإدخال
- رسائل التأكيد

#### 3. قائمة الأهداف
- عناوين البريد الإلكتروني
- الأسماء
- الأقسام

#### 4. جدول الإرسال
- تاريخ البدء
- تاريخ الانتهاء
- نمط الإرسال

## إنشاء حملة جديدة

### الخطوة 1: الوصول إلى صفحة الحملات

1. سجل الدخول إلى المنصة
2. انتقل إلى **التصيد** > **حملة جديدة**

### الخطوة 2: المعلومات الأساسية

```
اسم الحملة: حملة التوعية الأمنية Q1 2024
الوصف: اختبار وعي الموظفين بهجمات التصيد
التصريح: اختر من القائمة
```

### الخطوة 3: إعداد قالب البريد الإلكتروني

#### اختيار قالب جاهز

المنصة توفر قوالب جاهزة:

```
☐ تحديث كلمة المرور
☐ فاتورة مستحقة
☐ طرد في الانتظار
☐ تحديث أمني
☐ استطلاع رضا الموظفين
☐ مكافأة أو جائزة
☑ قالب مخصص
```

#### إنشاء قالب مخصص

**معلومات المرسل:**
```
اسم المرسل: فريق تقنية المعلومات
البريد الإلكتروني: it-support@company.com
```

**موضوع الرسالة:**
```
عاجل: تحديث أمني مطلوب لحسابك
```

**محتوى الرسالة:**
```html
مرحباً {{name}},

تم اكتشاف نشاط مشبوه على حسابك. لحماية بياناتك، يرجى 
تحديث كلمة المرور فوراً.

اضغط هنا للتحديث: {{tracking_link}}

إذا لم تقم بهذا الإجراء خلال 24 ساعة، سيتم تعليق حسابك.

مع تحياتنا،
فريق تقنية المعلومات
```

**المتغيرات المتاحة:**
- `{{name}}`: اسم الموظف
- `{{email}}`: البريد الإلكتروني
- `{{department}}`: القسم
- `{{tracking_link}}`: رابط التتبع
- `{{company}}`: اسم الشركة

**إخلاء المسؤولية (إلزامي):**
```
---
هذه رسالة اختبار من فريق الأمن السيبراني. إذا نقرت على 
الرابط، فهذا يعني أنك بحاجة لمزيد من التدريب على التعرف 
على رسائل التصيد الاحتيالي.
```

**ملاحظة:** سيتم إضافة إخلاء المسؤولية تلقائياً في نهاية الرسالة.

### الخطوة 4: إعداد صفحة الهبوط

#### نوع الصفحة

```
○ حصاد بيانات الاعتماد
○ تنزيل ملف
● استطلاع
○ صفحة مخصصة
```

#### تصميم الصفحة

**لحصاد بيانات الاعتماد:**
```html
<div class="login-form">
  <h2>تسجيل الدخول</h2>
  <form>
    <input type="email" name="username" placeholder="البريد الإلكتروني">
    <input type="password" name="password" placeholder="كلمة المرور">
    <button type="submit">تسجيل الدخول</button>
  </form>
</div>
```

**الحقول المراد جمعها:**
```
☑ اسم المستخدم
☑ كلمة المرور
☐ رقم الهاتف
☐ رقم الهوية
```

**رسالة بعد الإرسال:**
```
شكراً لك. تم تحديث حسابك بنجاح.

ملاحظة: هذا كان اختباراً أمنياً. لم يتم حفظ بياناتك الفعلية.
يرجى الانتباه للرسائل المشبوهة في المستقبل.
```

### الخطوة 5: إضافة الأهداف

#### الطريقة 1: إدخال يدوي

```

الاسم: أحمد محمد
القسم: تقنية المعلومات

[+ إضافة هدف آخر]
```

```csv

sara@company.com,سارة علي,الموارد البشرية
mohammed@company.com,محمد خالد,المالية
```

**خطوات الاستيراد:**
1. اضغط على **استيراد من CSV**
2. اختر الملف
3. تأكد من تطابق الأعمدة
4. اضغط على **استيراد**

#### الطريقة 3: مزامنة من Active Directory

```

DN الأساسي: OU=Users,DC=company,DC=com
المرشح: (&(objectClass=user)(mail=*))
```

## إنهاء الحملة

### الإنهاء اليدوي

إذا احتجت لإنهاء الحملة مبكراً:

1. افتح تفاصيل الحملة
2. اضغط على **إنهاء الحملة**
3. أكد الإنهاء

**سيتم تلقائياً:**
- إيقاف إرسال الرسائل المتبقية
- إرسال إشعارات لجميع الأهداف
- توليد التقرير النهائي

### الإنهاء التلقائي

الحملة تنتهي تلقائياً عند:
- الوصول لتاريخ الانتهاء المحدد
- إرسال جميع الرسائل
- انتهاء صلاحية التصريح

### إشعار الأهداف

بعد انتهاء الحملة، سيتم إرسال إشعار لجميع الأهداف:

```
الموضوع: إشعار: حملة التوعية الأمنية

مرحباً {{name}},

نود إبلاغك بأن الرسالة التي تلقيتها مؤخراً بعنوان "عاجل: 
تحديث أمني مطلوب" كانت جزءاً من حملة توعية أمنية تدريبية.

{{#if clicked}}
لقد نقرت على الرابط في الرسالة. هذا يعني أنك قد تكون عرضة 
لهجمات التصيد الاحتيالي الحقيقية.
{{/if}}

{{#if submitted}}
لقد أدخلت بيانات اعتماد في الصفحة. في هجوم حقيقي، كان من 
الممكن سرقة حسابك.
{{/if}}

نوصي بشدة بحضور دورة التوعية الأمنية القادمة.

مع تحياتنا،
فريق الأمن السيبراني
```

### توليد التقرير

#### أنواع التقارير

**1. تقرير تنفيذي:**
- ملخص عالي المستوى
- الإحصائيات الرئيسية
- التوصيات العامة

**2. تقرير تفصيلي:**
- تفاصيل كل هدف
- الخط الزمني الكامل
- البيانات المجمعة (مشفرة)

**3. تقرير تدريبي:**
- قائمة الموظفين الذين يحتاجون لتدريب
- مستويات المخاطر
- توصيات التدريب المخصصة

#### توليد التقرير

```bash
# تقرير PDF
npm run cli phishing:report \
  --campaign-id <campaign-id> \
  --type executive \
  --format pdf \
  --output report.pdf

# تقرير CSV للتحليل
npm run cli phishing:report \
  --campaign-id <campaign-id> \
  --type detailed \
  --format csv \
  --output results.csv
```

## أفضل الممارسات

### 1. التخطيط للحملة

```
✅ افعل:
- احصل على موافقة كتابية من الإدارة
- أبلغ قسم الموارد البشرية
- اختر توقيتاً مناسباً
- حدد أهدافاً واضحة

❌ لا تفعل:
- تطلق حملة بدون موافقة
- تستهدف موظفين في إجازة
- تستخدم مواضيع حساسة جداً
- تتجاهل الاعتبارات الثقافية
```

### 2. تصميم الحملة

```
✅ افعل:
- استخدم سيناريوهات واقعية
- اجعل الرسائل مقنعة لكن ليست مخيفة جداً
- ضمّن إخلاء المسؤولية
- اختبر الحملة قبل الإطلاق

❌ لا تفعل:
- تستخدم مواضيع مخيفة أو مهددة
- تنتحل شخصية مسؤولين حقيقيين
- تطلب معلومات حساسة جداً
- تستخدم شعارات الشركة بشكل مضلل
```

### 3. أثناء الحملة

```
✅ افعل:
- راقب التفاعلات في الوقت الفعلي
- كن مستعداً للإجابة على الأسئلة
- وثق جميع الأحداث
- احترم خصوصية الموظفين

❌ لا تفعل:
- تترك الحملة دون مراقبة
- تتجاهل الشكاوى
- تشارك النتائج قبل الانتهاء
- تستخدم البيانات لأغراض أخرى
```

### 4. بعد الحملة

```
✅ افعل:
- أبلغ جميع الأهداف فوراً
- قدم تدريباً للموظفين المعرضين للخطر
- شارك النتائج مع الإدارة
- احذف البيانات الحساسة

❌ لا تفعل:
- تؤخر إبلاغ الأهداف
- تستخدم النتائج للعقاب
- تحتفظ بالبيانات أطول من اللازم
- تشارك النتائج الفردية علناً
```

## الأمان والخصوصية

### تشفير البيانات

جميع البيانات الحساسة مشفرة:

```
✓ بيانات الاعتماد المدخلة: AES-256
✓ عناوين IP: مجزأة (hashed)
✓ البيانات الشخصية: مشفرة في قاعدة البيانات
✓ التقارير: محمية بكلمة مرور
```

### الحذف التلقائي

```
البيانات الحساسة تُحذف تلقائياً:
- بيانات الاعتماد: بعد 30 يوماً
- عناوين IP: بعد 90 يوماً
- البيانات الشخصية: بعد 180 يوماً
- الإحصائيات: تُحفظ بشكل مجهول
```

### ضوابط الوصول

```
الوصول للبيانات محدود:
✓ مدراء الحملات: الإحصائيات فقط
✓ مسؤولو الأمن: جميع البيانات
✓ المدققون: سجلات التدقيق
✗ الآخرون: لا وصول
```

## استكشاف الأخطاء

### "فشل إرسال الرسائل"

**الأسباب:**
- مشاكل في خادم البريد
- عناوين بريد إلكتروني غير صالحة
- الرسائل محظورة كبريد مزعج

**الحلول:**
```bash
# التحقق من إعدادات البريد
npm run cli email:test --to test@company.com

# التحقق من سجلات البريد
npm run cli email:logs --campaign-id <id>
```

### "معدل فتح منخفض جداً"

**الأسباب:**
- الرسائل تذهب لمجلد البريد المزعج
- الموضوع غير جذاب
- التوقيت غير مناسب

**الحلول:**
- راجع إعدادات SPF/DKIM/DMARC
- اختبر مواضيع مختلفة
- أرسل في أوقات مختلفة

### "معدل نقر عالي جداً"

**التفسير:**
- قد يكون مؤشراً على ضعف الوعي الأمني
- أو أن الرسالة مقنعة جداً

**الإجراءات:**
- راجع محتوى الرسالة
- قدم تدريباً عاجلاً
- خطط لحملات متابعة

## الخلاصة

حملات التصيد التدريبية هي أداة قوية لتحسين الوعي الأمني. تذكر دائماً:

1. ✅ احصل على موافقة كتابية
2. ✅ الهدف هو التدريب، ليس العقاب
3. ✅ احترم خصوصية الموظفين
4. ✅ أبلغ الأهداف بعد الانتهاء
5. ✅ احذف البيانات الحساسة
