# دليل البدء السريع - منصة اختبار الاختراق والأمن الهجومي

## مرحباً بك في المنصة

هذا الدليل سيساعدك على البدء باستخدام منصة اختبار الاختراق والأمن الهجومي في أقل من 15 دقيقة.

## ⚠️ إخلاء المسؤولية القانونية

**تحذير مهم:** هذه المنصة مصممة حصرياً للاستخدام القانوني والأخلاقي في اختبار الاختراق المصرح به. يجب الحصول على تصريح كتابي صريح قبل إجراء أي اختبار. الاستخدام غير المصرح به لهذه الأدوات يعتبر غير قانوني ويخضع للمساءلة الجنائية.

## المتطلبات الأساسية

- Node.js 18 أو أحدث
- PostgreSQL 14 أو أحدث
- Redis 6 أو أحدث
- حساب مستخدم مع الصلاحيات المناسبة

## الخطوة 1: التثبيت

### 1.1 استنساخ المشروع

```bash
git clone https://github.com/your-org/penetration-testing-platform.git
cd penetration-testing-platform
```

### 1.2 تثبيت التبعيات

```bash
npm install
```

### 1.3 إعداد متغيرات البيئة

انسخ ملف `.env.example` إلى `.env` وقم بتعديل القيم:

```bash
cp .env.example .env
```

قم بتحرير ملف `.env` وأضف التكوينات الخاصة بك:

```env
# Database
DATABASE_URL=postgresql://user:password@localhost:5432/pentest_db

# Redis
REDIS_URL=redis://localhost:6379

# JWT Secret
JWT_SECRET=your-super-secret-jwt-key-change-this

# Encryption
ENCRYPTION_KEY=your-32-character-encryption-key

# Server
PORT=3000
NODE_ENV=development
```

### 1.4 إعداد قاعدة البيانات

```bash
# إنشاء قاعدة البيانات
npm run db:create

# تشغيل الترحيلات
npm run db:migrate
```

### 1.5 تشغيل المنصة

```bash
# وضع التطوير
npm run dev

# وضع الإنتاج
npm run build
npm start
```

## الخطوة 2: تسجيل الدخول الأول

### 2.1 الوصول إلى المنصة

افتح المتصفح وانتقل إلى:
```
http://localhost:3000
```

### 2.2 تسجيل الدخول

استخدم بيانات الاعتماد الافتراضية للمسؤول:
- **اسم المستخدم:** admin
- **كلمة المرور:** Admin@123 (يجب تغييرها فوراً)

### 2.3 تفعيل المصادقة متعددة العوامل (MFA)

بعد تسجيل الدخول الأول، يُنصح بشدة بتفعيل MFA:

1. انتقل إلى **الإعدادات** > **الأمان**
2. اضغط على **تفعيل المصادقة متعددة العوامل**
3. امسح رمز QR باستخدام تطبيق المصادقة (Google Authenticator، Authy، إلخ)
4. أدخل الرمز للتأكيد

## الخطوة 3: تحميل تصريح

قبل إجراء أي اختبار، يجب تحميل تصريح قانوني صالح.

### 3.1 إنشاء تصريح جديد

1. انتقل إلى **التصاريح** > **تصريح جديد**
2. املأ المعلومات المطلوبة:
   - **اسم المنظمة:** اسم الشركة أو المنظمة المصرح لها
   - **تاريخ البدء:** تاريخ بدء صلاحية التصريح
   - **تاريخ الانتهاء:** تاريخ انتهاء صلاحية التصريح
   - **الموقع من قبل:** اسم الشخص المخول بالتوقيع

### 3.2 تحديد نطاق العمل

حدد الأنظمة والشبكات المصرح باختبارها:

- **النطاقات (Domains):** example.com, test.example.com
- **نطاقات IP:** 192.168.1.0/24, 10.0.0.0/16
- **الشبكات اللاسلكية:** SSID: CompanyWiFi, BSSID: XX:XX:XX:XX:XX:XX
- **نطاقات البريد الإلكتروني:** @company.com

### 3.3 تحديد العمليات المصرح بها

اختر أنواع الاختبارات المسموح بها:
- ☑ فحص تطبيقات الويب
- ☑ حملات التصيد الاحتيالي
- ☑ اختبار الشبكات اللاسلكية

### 3.4 تحميل الوثيقة

قم بتحميل نسخة رقمية موقعة من التصريح (PDF):
- اضغط على **اختيار ملف**
- حدد ملف التصريح الموقع
- اضغط على **تحميل**

## الخطوة 4: إجراء أول فحص

### 4.1 فحص تطبيق ويب

1. انتقل إلى **الفحص** > **فحص جديد**
2. أدخل عنوان URL المستهدف: `https://example.com`
3. اختر التصريح المناسب من القائمة
4. حدد أنواع الثغرات المراد اختبارها:
   - ☑ SQL Injection
   - ☑ Cross-Site Scripting (XSS)
   - ☑ CSRF
   - ☑ Directory Traversal
5. اضبط الإعدادات:
   - **العمق الأقصى:** 3
   - **الطلبات القصوى:** 1000
   - **احترام robots.txt:** نعم
6. اضغط على **بدء الفحص**

### 4.2 متابعة التقدم

- شاهد حالة الفحص في الوقت الفعلي
- راقب عدد الطلبات المرسلة
- شاهد الثغرات المكتشفة فور اكتشافها

### 4.3 عرض النتائج

بعد اكتمال الفحص:
1. انتقل إلى **الفحص** > **السجل**
2. اضغط على الفحص لعرض التفاصيل
3. راجع الثغرات المكتشفة
4. اضغط على **توليد تقرير** للحصول على تقرير شامل

## الخطوة 5: توليد التقرير

### 5.1 اختيار التنسيق

اختر تنسيق التقرير المناسب:
- **PDF:** للتقارير الرسمية والعروض التقديمية
- **HTML:** للعرض في المتصفح
- **JSON:** للتكامل مع أدوات أخرى
- **CSV:** لتحليل البيانات في Excel

### 5.2 تخصيص المحتوى

حدد الأقسام المراد تضمينها:
- ☑ الملخص التنفيذي
- ☑ قائمة الثغرات
- ☑ التفاصيل الفنية
- ☑ توصيات الإصلاح
- ☑ الإحصائيات والرسوم البيانية

### 5.3 تنزيل التقرير

اضغط على **توليد وتنزيل** للحصول على التقرير.

## الأوامر السريعة

### إدارة المنصة

```bash
# بدء المنصة
npm start

# إيقاف المنصة
npm stop

# إعادة تشغيل المنصة
npm restart

# عرض السجلات
npm run logs

# فحص الحالة
npm run health-check
```

### إدارة قاعدة البيانات

```bash
# إنشاء نسخة احتياطية
npm run db:backup

# استعادة من نسخة احتياطية
npm run db:restore

# تنظيف البيانات القديمة
npm run db:cleanup
```

## استخدام واجهة سطر الأوامر (CLI)

### فحص سريع

```bash
# فحص نطاق
npm run cli scan --url https://example.com --auth-id <authorization-id>

# عرض حالة الفحص
npm run cli scan:status --session-id <session-id>

# إيقاف الفحص
npm run cli scan:stop --session-id <session-id>
```

### إدارة التصاريح

```bash
# عرض جميع التصاريح
npm run cli auth:list

# التحقق من صلاحية تصريح
npm run cli auth:validate --auth-id <authorization-id>

# إلغاء تصريح
npm run cli auth:revoke --auth-id <authorization-id>
```

## استكشاف الأخطاء الشائعة

### خطأ: "لا يمكن الاتصال بقاعدة البيانات"

**الحل:**
1. تأكد من تشغيل PostgreSQL
2. تحقق من صحة `DATABASE_URL` في ملف `.env`
3. تأكد من وجود قاعدة البيانات

```bash
# التحقق من حالة PostgreSQL
sudo systemctl status postgresql

# إنشاء قاعدة البيانات يدوياً
createdb pentest_db
```

### خطأ: "التصريح غير صالح"

**الحل:**
1. تحقق من تاريخ انتهاء التصريح
2. تأكد من أن الهدف ضمن نطاق العمل المصرح به
3. تحقق من أن نوع العملية مصرح به

### خطأ: "فشل الفحص"

**الحل:**
1. تحقق من إمكانية الوصول إلى الهدف
2. راجع السجلات للحصول على تفاصيل الخطأ
3. تأكد من عدم حظر عنوان IP الخاص بك

```bash
# عرض السجلات
npm run logs -- --level error
```
