   🔧 إصلاح جدول sessions
═══════════════════════════════════════════════════════════

المشكلة: جدول sessions لا يحتوي على الأعمدة المطلوبة

═══════════════════════════════════════════════════════════
   الحل: نفذ هذا الكود في phpMyAdmin
═══════════════════════════════════════════════════════════

1. افتح phpMyAdmin
2. اختر قاعدة البيانات "web scanner"
3. اضغط على تبويب SQL
4. انسخ والصق هذا الكود:

┌─────────────────────────────────────────────────────────┐
│ USE `web scanner`;                                      │
│                                                         │
│ ALTER TABLE sessions                                    │
│   ADD COLUMN expires_at DATETIME AFTER created_at;     │
│                                                         │
│ ALTER TABLE sessions                                    │
│   ADD COLUMN ip_address VARCHAR(45) AFTER expires_at;  │
│                                                         │
│ ALTER TABLE sessions                                    │
│   ADD COLUMN user_agent TEXT AFTER ip_address;         │
│                                                         │
│ ALTER TABLE sessions                                    │
│   ADD COLUMN last_activity DATETIME AFTER user_agent;  │
└─────────────────────────────────────────────────────────┘

5. اضغط Go أو تنفيذ

═══════════════════════════════════════════════════════════
   بعد التحديث
═══════════════════════════════════════════════════════════

ارجع إلى صفحة تسجيل الدخول وجرب مرة أخرى:

   http://localhost:3002/

   اسم المستخدم: admin
   كلمة المرور: 123456
