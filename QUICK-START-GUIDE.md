## 🔧 Troubleshooting

### Problem: "localhost refused to connect"
**Solution:** Run `تشغيل-محسّن.bat`

### Problem: "Node.js not installed"
**Solution:** Download from https://nodejs.org

### Problem: "Libraries not installed"
**Solution:** Run `npm install`

### Problem: "Port 3001 in use"
**Solution:** Run `taskkill /F /IM node.exe`
