# واجهة منصة اختبار الاختراق

## نظرة عامة

واجهة ويب احترافية كاملة لمنصة اختبار الاختراق والأمن الهجومي.

## المميزات

### 🎨 التصميم
- واجهة عربية كاملة (RTL)
- تصميم عصري وجذاب
- متجاوب مع جميع الأجهزة
- ألوان متدرجة احترافية
- رسوم متحركة سلسة

### 📊 لوحة التحكم
- إحصائيات فورية
- عرض النشاط الأخير
- إجراءات سريعة
- تحديث تلقائي

### 🔍 فحص الويب
- إنشاء عمليات فحص جديدة
- عرض نتائج الفحص
- تصنيف الثغرات حسب الخطورة
- تفاصيل كاملة لكل ثغرة

### 🎣 حملات التصيد
- إنشاء حملات جديدة
- إدارة الأهداف
- إحصائيات تفاعلية
- تتبع النتائج

### 🌐 تحليل الشبكات
- اختبارات شبكة متنوعة
- اكتشاف الأجهزة
- فحص المنافذ
- رسم خريطة الشبكة

### 📄 التقارير
- إنشاء تقارير متعددة الأنواع
- صيغ متنوعة (PDF, HTML, JSON)
- رسوم بيانية
- توصيات أمنية

### 🔐 التصاريح
- إدارة التصاريح
- التحقق من الصلاحيات
- تتبع الحالة

### 📝 السجلات
- سجلات التدقيق
- تتبع الأنشطة
- أمان وشفافية

## التقنيات المستخدمة

- **HTML5** - البنية
- **CSS3** - التصميم والأنماط
- **JavaScript (ES6+)** - المنطق والتفاعل
- **Font Awesome** - الأيقونات
- **Fetch API** - الاتصال بالخادم

## المكونات الرئيسية

### API Client (`api.js`)
عميل API موحد للتواصل مع الخادم:
- إدارة التوكن
- معالجة الأخطاء
- طلبات موحدة

### Auth Manager (`auth.js`)
إدارة المصادقة:
- تسجيل الدخول
- تسجيل الخروج
- التحقق من الجلسة

### App (`main.js`)
المنطق الرئيسي للتطبيق:
- التنقل بين الصفحات
- إدارة الحالة
- معالجة الأحداث

### Dashboard (`dashboard.js`)
لوحة التحكم:
- تحميل الإحصائيات
- عرض النشاط
- التحديث التلقائي

### Web Scanner (`web-scan.js`)
فحص المواقع:
- إنشاء فحص جديد
- عرض النتائج
- تصنيف الثغرات

### Phishing Manager (`phishing.js`)
إدارة حملات التصيد:
- إنشاء حملات
- إدارة الأهداف
- عرض الإحصائيات

### Network Tester (`network.js`)
اختبار الشبكات:
- إنشاء اختبارات
- عرض الأجهزة
- تحليل النتائج

### Reports Manager (`reports.js`)
إدارة التقارير:
- إنشاء تقارير
- تحميل التقارير
- صيغ متعددة

## التخصيص

### تغيير الألوان

عدّل المتغيرات في `main.css`:

```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    /* ... */
}
```

### إضافة صفحة جديدة

1. أضف عنصر في القائمة الجانبية
2. أضف div للصفحة في المحتوى
3. أضف دالة تحميل في `main.js`

### تخصيص API

عدّل `API_BASE_URL` في `api.js`:

```javascript
const API_BASE_URL = '/api/v1';
```
