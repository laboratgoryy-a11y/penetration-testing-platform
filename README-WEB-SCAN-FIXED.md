```typescript
// قبل: كان يحفظ في النهاية فقط
```

#### ب. تحديث التقدم بعد كل صفحة
```typescript
// حساب التقدم الدقيق
const progress = 50 + Math.floor((pagesProcessed / crawlResults.length) * 50);

await this.scanSession.update(sessionId, {
  totalRequests,
  totalVulnerabilities: discoveredVulnerabilities.length,
});
```

```typescript
console.log(`🚀 Starting scan ${sessionId} for ${targetUrl}`);
```

### 4. معالجة أخطاء شاملة

```typescript
catch (error) {
  console.error(`❌ Scan ${sessionId} failed:`, error);
  
  // إيقاف المستخدم
  if (error instanceof AbortError) {
    console.log('⏹️ Scan stopped by user');
    return;
  }
  
  // خروج عن النطاق
  if (error instanceof ScopeViolationError) {
    console.log('🚫 Scope violation detected');
    await this.scanSession.update(sessionId, {
      status: 'STOPPED',
      completedAt: new Date(),
    });
    throw error;
  }
  
  // خطأ عام
  await this.scanSession.update(sessionId, {
    status: 'FAILED',
    completedAt: new Date(),
  });
  
  throw error;
}
```

## 📝 خطوات الاستخدام التفصيلية

### 1️⃣ أدخل رابط الموقع المستهدف

```
مثال: https://owasp.org/www-project-juice-shop/
```

**ملاحظة**: تأكد من أن الرابط صحيح ويبدأ بـ `http://` أو `https://`

### 2️⃣ اختر التصريح

- يتم تحميل التصاريح النشطة تلقائياً
- إذا لم يكن لديك تصريح، أنشئ واحداً:
  ```
  http://localhost:3000/إنشاء-تصريح-تجريبي.html
  ```

**نصيحة**: تأكد من أن التصريح يشمل نطاق الموقع المستهدف

### 3️⃣ اختر نوع الفحص

- **سريع**: للاختبار السريع (2-5 دقائق)
- **قياسي**: للاستخدام العادي (5-10 دقائق) ⭐ **موصى به**
- **عميق**: للفحص الشامل (10-20 دقيقة)

### 4️⃣ اضغط "بدء الفحص"

سترى:
- ✅ رسالة تأكيد بدء الفحص
- ✅ معرف الفحص (Scan ID)
- ✅ إخفاء النموذج وإظهار شاشة التقدم

### 5️⃣ راقب التقدم

**شريط التقدم:**
- يتحدث كل ثانيتين
- يعرض النسبة المئوية (0% - 100%)

**الإحصائيات:**
- عدد الصفحات المفحوصة
- عدد الثغرات المكتشفة
- الوقت المنقضي
- الحالة الحالية

**السجلات المباشرة:**
```

[10:30:16] ✅ تم بدء الفحص بنجاح! ID: scan-1234567890
[10:30:18] 📊 التقدم: 10% | صفحات: 5 | ثغرات: 0
[10:30:20] 📊 التقدم: 25% | صفحات: 12 | ثغرات: 1

[10:30:28] ✅ تم تحميل النتائج بنجاح
```

### 6️⃣ اعرض النتائج

**الملخص الشامل:**
- إجمالي الطلبات
- إجمالي الثغرات
- تصنيف حسب الخطورة (حرجة، عالية، متوسطة، منخفضة)

**قائمة الثغرات:**
- نوع الثغرة
- مستوى الخطورة (بألوان مختلفة)

### المشكلة 3: "الفحص بطيء جداً"

**الأعراض:**
- الفحص يستغرق أكثر من 20 دقيقة
- التقدم بطيء جداً

**الحل:**
1. استخدم "فحص سريع" بدلاً من "عميق"
2. قلل عدد أنواع الثغرات المختبرة
3. تحقق من سرعة الإنترنت
4. تحقق من أن الموقع المستهدف يستجيب بسرعة

### المشكلة 4: "لا تظهر الثغرات"

**الأعراض:**
- الفحص يكتمل بنجاح
- لكن عدد الثغرات = 0

**الحل:**
1. **جرب موقع اختبار معروف**
   ```
   https://owasp.org/www-project-juice-shop/
   ```

2. **افتح Console (F12)**
   - تحقق من السجلات
   - ابحث عن رسائل "Vulnerability found"

3. **تأكد من أن الموقع يحتوي على ثغرات فعلاً**
   - ليس كل موقع يحتوي على ثغرات
   - المواقع الآمنة لن تظهر ثغرات

4. **تحقق من أنواع الثغرات المختبرة**
   - تأكد من اختيار جميع الأنواع
   - جرب أنواع مختلفة

### المشكلة 5: "الفحص يتوقف فجأة"

**الأعراض:**
- الفحص يتوقف قبل الانتهاء
- الحالة تتحول إلى STOPPED أو FAILED

**الحل:**
1. **افتح Console (F12)**
   - ابحث عن رسائل الخطأ
   - تحقق من آخر سجل

2. **تحقق من التصريح**
   - تأكد من أن التصريح لا يزال نشطاً
   - تأكد من أن النطاق صحيح

3. **تحقق من الاتصال بالإنترنت**
   - تأكد من أن الإنترنت يعمل
   - تأكد من أن الموقع المستهدف متاح

4. **أعد المحاولة**
   - اضغط "فحص جديد"
   - جرب مرة أخرى
